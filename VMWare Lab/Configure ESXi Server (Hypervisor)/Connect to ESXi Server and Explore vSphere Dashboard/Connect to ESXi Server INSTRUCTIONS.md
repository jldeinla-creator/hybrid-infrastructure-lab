# vSphere Web Client — Quick Guide

## 1. Access ESXi

1. Open a web browser.
2. Enter the **ESXi server IP address**.
3. Log in with the appropriate credentials.

Example:

```text
https://<ESXi-IP>
```

## 2. Main Functions

### Actions

Use **Actions** to:

```text
Reboot
Shutdown
Enable/Disable SSH
Enable/Disable ESXi Shell
Maintenance Mode
Support Bundle
```

### Manage

Use **Manage** to view or configure:

```text
System
Hardware
Licensing
Packages
Services
Users
```

### Monitor

Use **Monitor** to check:

```text
CPU
Memory
Network
Disk
Events
Tasks
Logs
Notifications
```

### Storage

Manage:

```text
Datastores
Storage Devices
Storage Capacity
```

### Networking

Manage:

```text
Virtual Switches
Networks
Management Network
VM Networks
```

## 3. Virtual Machines

From the Web Client, you can:

```text
Create Virtual Machines
Register Virtual Machines
Manage Virtual Machines
```

## 4. Quick Summary

```text
Actions    → Host operations
Manage     → System configuration
Monitor    → Performance and logs
Storage    → Datastores and storage
Networking → Virtual switches and networks
VMs        → Create and manage virtual machines
```

## 5. Interview Answer

> “The vSphere Web Client is a web-based management interface for an ESXi host. I use it to create and manage virtual machines, monitor CPU and memory, manage storage and networking, view events and logs, and perform administrative tasks such as maintenance mode and SSH management.”
