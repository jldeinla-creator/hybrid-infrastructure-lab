# VMware Workstation Player — Quick Installation

## 1. Check Requirements

* Windows PC
* 4 GB+ RAM
* 20 GB+ free disk space
* Internet connection

## 2. Download

1. Go to the **Broadcom Support Portal**.
2. Sign in.
3. Go to **VMware Downloads**.
4. Select **VMware Workstation Player**.
5. Download the required version.

## 3. Install

1. Run the downloaded installer.
2. Click **Next**.
3. Accept the license agreement.
4. Keep the default settings.
5. Click **Install**.
6. Click **Finish**.

## 4. Launch

1. Open **VMware Workstation Player**.
2. Select the appropriate license/use option.
3. Click **Continue**.

## 5. Verify

Confirm that VMware Workstation opens successfully and that **Create a New Virtual Machine** is available.

**Status:** ✅ Installation Complete
